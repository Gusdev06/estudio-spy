# WhatsApp — vazio (de propósito)

Nenhum dos 13 criativos escalados de `go.zappdetect.com` é sobre WhatsApp.

Chequei a copy dos **27 anúncios**: zero menção a WhatsApp/zap/wpp. O nome do produto
("zappdetect") puxa pra "zap", mas todos os anúncios vendem a mesma coisa — **espionar
perfil de Instagram** (DMs, stories vistos, close friends, localização, "mensagens
apagadas"). Toda a UI que aparece nos vídeos é do Instagram.

Por isso os 13 foram todos pra `../instagram/`. Se aparecer variante de WhatsApp numa
próxima coleta, é aqui que ela entra.
