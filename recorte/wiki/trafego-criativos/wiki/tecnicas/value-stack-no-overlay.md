# Value Stack no Overlay

Empilhar a oferta inteira no overlay da imagem, legível numa olhada só. É o que
transforma uma foto crível ([[believability-reveal]]) num anúncio que converte.

## A pilha (do [[criativo-campeao-52515797525534]])
- `+300 PROMPTS` → **o quê**
- `Onl* F and F*anvue` → **onde monetizar** (plataformas censuradas → [[censura-plataforma-asterisco]])
- `HYPER-REALISTIC AI` (barra laranja) → **o mecanismo/diferencial**, destacado
- `JUST $6,99` → **âncora de preço** baixíssimo, gatilho de impulso

## Regras
- Tudo captável numa olhada (feed é scroll rápido).
- O reveal "HYPER-REALISTIC AI" carrega o choque do [[believability-reveal]].
- Ao variar o hook, mantém a pilha (muda só a linha de cima) → [[variar-uma-alavanca-por-vez]].

## Divergência aberta
Overlay anuncia **$6,99**, mas a [[oferta-300-prompts]] vende **$12,99**. Confirmar se
é preço de entrada ou criativo antigo (impacta expectativa no checkout).

## Conecta com
- [[believability-reveal]] — a foto entrega, o overlay converte
- [[censura-plataforma-asterisco]] — parte da pilha
